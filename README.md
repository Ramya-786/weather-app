# weather-app
# 🌦️ Weather App

A simple and modern Weather App built using HTML, CSS, and JavaScript.  
It shows real-time weather details and location map using API integration.

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🌡️ Temperature display (Celsius)  
- ☁️ Weather condition  
- 🗺️ Location map view  
- 🎤 Voice input (speech to text)  
- ✨ Animated UI design  

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  
- OpenWeather API
